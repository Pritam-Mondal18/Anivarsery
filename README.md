# Chandana & Arnab · শুভ বিবাহ বার্ষিকী

---

## 🌟 Features Included

1. **Gate / Cover Screen & Royal Curtains:**
   - Ornate royal red & gold entrance gate with animated velvet drapes and golden tassels.
   - Traditional auspicious invocation: **"প্রজাপতয়ে নমঃ"** with fluttering gold butterfly.
   - Main title: **"শুভ বিবাহ বার্ষিকী"** (Shubho Bibaho) in shimmering gold foil.
   - Couple names: **"Chandana & Arnab"** and date **"26 · 11 · 2025"**.
   - Interactive **"আমন্ত্রণপত্র খুলুন"** (Open Invitation) button with glowing pulse ring.
   - Opening curtain animation and falling rose petals effect.

2. **Background Shehnai / Wedding Music:**
   - Background audio track (`bgm.mp3`) with soft volume fade-in when the invitation is opened.
   - Floating interactive vinyl disc button with animated soundwave visualizer.
   - Click to easily mute / unmute anytime.

3. **Falling Rose Petals (Canvas Physics Engine):**
   - Realistic 3D petal physics: fluttering, wind drift, and rotation across sections.

4. **Hero Stage Section:**
   - Grand chandelier and decorative floral arches (`roses-corner.webp`, `garland.webp`).
   - Ornate gold frame displaying your couple photo (`pic.jpeg`).
   - Integrated stage video loops using your video (`vdo2.mp4`).
   <!-- - Parents' names: "Daughter of Mitali & Subrata Sen" & "Son of Rupa & Debashis Mukherjee". -->
   - Smooth animated scroll cue.

5. **Couple Section (বর ও কনে):**
   - Individual portraits of the Bride and Groom (`pic.jpeg`) in authentic Mughal arches.
   - Witty and sweet personal bios in authentic Bengali:
     - *Bride:* " · "
     - *Groom:* " · "

6. **Traditional Bengali Lagna Patrika / Wedding Card (প্রেমপত্র):**
   - Classical wax monogram seal with "A & R" initials.
   - Interactive folding card with textured parchment paper and Bengali alpona motifs.
   - Tabs to switch between **"কন্যাপক্ষ"** (Bride's family: Behala, Kolkata) and **"বরপক্ষ"** (Groom's family: Khardha, North 24 Pargana).

7. **Sacred Wedding Mantra (শুভ পরিণয়ের মন্ত্র):**
   - Sanskrit shloka:
     > *যদেতৎ হৃদয়ং তব তদস্তু হৃদয়ং মম। যদিদং হৃদয়ং মম তদস্তু হৃদয়ং তব॥*
   - Poetic Bengali translation:
     > *তোমার এই হৃদয় আমার হোক, আমার এই হৃদয় তোমার।*

8. **Date & Live Countdown Timer (শুভ দিন):**
   - Real-time live countdown ticking in days, hours, minutes, and seconds to **26 November 2025**.
   - Traditional Bengali calendar display for November 2025 with Wednesday, the 26th highlighted.
   - "Add to Google Calendar" button with exact wedding times and venue coordinates.

9. **Our Kolkata Photo Story (আমাদের কলকাতা):**
   - Romantic journey across Kolkata's iconic heritage spots:
     - Prinsep Ghat (*"প্রথম দেখা"*)
     - College Street (*"পুরোনো বইয়ের গন্ধ"*)

## 🚀 How to Run Locally

You can run the project in any browser with Node.js:

```bash
# Start local development server
npm run dev
# or
npm start
```
Then open: **[http://localhost:3000](http://localhost:3000)**

Open on google: https://pritam-mondal18.github.io/Anivarsery/

## 🌐 How to Deploy to Vercel / Netlify / GitHub Pages

This is a pure static frontend (zero backend required):

- **Vercel:** Run `npx vercel` or push this folder to GitHub and import it on Vercel.
- **Netlify:** Drag and drop this folder directly into Netlify Drop.
- **GitHub Pages:** Enable GitHub Pages for the repository root.
